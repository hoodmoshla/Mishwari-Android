# دليل اليمن الإداري المضمن

## المصدر والترخيص

المصدر هو [OCHA Yemen / HDX — Yemen: Subnational Administrative Boundaries (COD-AB)](https://data.humdata.org/dataset/cod-ab-yem)، ومصدر البيانات الأصلي المسجل هو **Central Statistical Organization (CSO)**. بيانات HDX تعيّن ترخيص **Creative Commons Attribution for Intergovernmental Organisations (CC BY-IGO 3.0)**؛ راجع [نص الترخيص](https://creativecommons.org/licenses/by/3.0/igo/legalcode). الإسناد المرفق في `app/src/main/assets/yemen-directory.json` يذكر OCHA Yemen / HDX (COD-AB)، وCSO، والترخيص والرابط.

## المحتوى المتحقق

الملف المضمن يحوي **22 محافظة و335 مديرية** (358 سجلًا إداريًا مع سجل اليمن). هذه الأعداد مطابقة للسجلات الفعلية في الملف وللمصدر المستخرج المحفوظ في `research/yemen_admin_names.json` والملاحظات في `research/yemen-admin-data-notes.md`. لذلك لا يُختزل العدد إلى 333 ولا تُضاف أسماء أو أعداد غير موجودة في المصدر.

يُحمل الدليل مع التطبيق ويُدرج تلقائيًا في قاعدة البيانات عند أول فتح لها؛ لا يحتاج تنزيلًا أو اتصالًا. الإدراج يحافظ على السجلات الموجودة عبر `INSERT OR IGNORE` للمعرّفات المستقرة، فلا يستبدل الأماكن المخصصة أو بيانات المستخدم ذات المعرّف نفسه. يحتوي الدليل أسماءً ورموزًا/علاقات إدارية فقط؛ لا يتضمن حدودًا أو إحداثيات ولا يجعل المحافظة أو المديرية نقطة وصول للتنبيه. تبقى الأماكن التي ينشئها المستخدم منفصلة عن الدليل.

## تاريخ البيانات وحدود الاعتماد

بيانات HDX تسجل صلاحية المصدر ابتداءً من **2019-11-22** ومراجعة للدقة والاكتمال بتاريخ **2024-12-23**. ووفق ملاحظات التحقق المحلية، لا تمثل هذه المراجعة تأكيدًا للتغييرات الإدارية حتى 2026؛ لذلك يُستخدم الملف مرجع أسماء عمليًا دون ادعاء أنه سجل إداري راهن أو مرجع قانوني. راجع الجهة اليمنية المختصة أو OCHA قبل الاعتماد الرسمي أو التحديث.

## تحديث الدليل

استيراد JSON بديل متاح من **الإعدادات ← الأذونات والخصوصية (متقدم)**. افحص المصدر والترخيص وتاريخ التحديث والعلاقات قبل اعتماد أي تحديث؛ الاستيراد الإضافي لا يعني التحقق المستقل من محتواه. لا تُفعّل مراقبة الوصول تلقائيًا للبيانات المستوردة.
