# مشواري — Mishwari Android

مستودع خاص لتطبيق أندرويد عربي للطلبات والمشاوير وتنبيهات الوصول.

الكود الجاري واختباراته محفوظة في [فرع التنفيذ](https://github.com/hoodmoshla/Mishwari-Android/tree/codex/initial-implementation)، ولا تُدمج النسخة غير المتحققة إلى `main`.

راجع [عمليات البناء وملفات APK](https://github.com/hoodmoshla/Mishwari-Android/actions). إنشاء ملفات المشروع واختبارها لا يثبت وحده نجاح كشف الموقع في الخلفية؛ يلزم اختبار ميداني موثق قبل الإصدار الإنتاجي.
